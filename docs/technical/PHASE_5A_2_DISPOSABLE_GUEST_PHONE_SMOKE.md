## Safety design

The smoke test is isolated from production:

- Fresh `%TEMP%\terabooth-guest-phone-*` directory per run.
- Separate SQLite DB under that temp directory.
- Port **8788**, never 8787.
- Independent random API token and delivery secret generated by PowerShell;
  neither is printed.
- `TERABOOTH_PRINTER=mock`.
- `TERABOOTH_PUBLIC_BASE_URL` is the supplied LAN URL.
- Production port 8787 is inspected read-only with `Get-NetTCPConnection`;
  it is never stopped or changed.
- No camera, CascableCore, DNP, iPad or Flutter changes.
- No public internet exposure.
- Guest URL is printed because it is the operator's access link; it is clearly
  labelled sensitive.

## Workflow

The PowerShell wrapper:

1. Refuses port 8787.
2. Validates the public URL is not localhost/loopback.
3. Generates independent cryptographically random secrets in-process.
4. Starts the existing `scripts/run_bridge.py` with host `0.0.0.0`, port 8788,
   mock printer and a fresh temp data root.
5. Invokes the Python smoke helper.

The helper:

- Verifies unauthenticated `/v1/health` returns 401.
- Verifies authenticated health.
- Creates a real mock 2-photo `duo_4x6_v1` print job with two generated JPEGs.
- Waits for the mock job and GIF.
- Obtains the delivery token from the API's `delivery_url`.
- Verifies the URL uses the configured LAN origin.
- Checks guest page, manifest, both originals, branded strip, ZIP, GIF and QR.
- Prints only test status, the guest URL, QR file location and instructions.
- Keeps the server running until Ctrl+C (unless `-SelfTest`).
- On shutdown terminates only its own child process and removes only its own
  temp directory.


```text
GUEST_URL=http://192.168.8.192:8788/d/<token>
```

Open that URL on a phone connected to the same Wi-Fi. The QR image is written
under the disposable temp directory and the path is printed while the server
runs. Stop with **Ctrl+C** to clean up.

